# d-025: Directory listings

- Status: open (owner)
- Priority: P3
- Added: 2026-11-04

## What

List the school on a handful of directories that already rank for local instructor searches, for
example GoRoadie (it has a page for each language), Cademy, FreeIndex, Yell and a Nextdoor business
page.

## Why

More places to be found, and each one links to the site.

## Done when

Five to eight listings are live.

## Notes

- Use exactly the same name, phone number and website on every one.
- A few good listings beat many poor ones.
