# d-001: Enforce HTTPS

- Status: open (owner)
- Priority: P1
- Added: 2026-10-12

## What

Tick **Enforce HTTPS** in the GitHub repo's Settings → Pages, signed in as the repo owner.

## Why

`https://seymadrivingschool.com` works, but a plain `http://` link is still served over HTTP, so those visitors see "Not Secure".

## Done when

`curl -I http://seymadrivingschool.com/` answers with a 301 to the `https://` address.

## Notes

- 2026-10-12: all four GitHub Pages servers returned 200 over plain HTTP with no redirect.
