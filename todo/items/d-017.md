# d-017: Bing Webmaster Tools and IndexNow

- Status: in progress
- Priority: P1
- Added: 2026-11-04

## What

1. In Bing Webmaster Tools, sign in and choose **Import from Google Search Console**. This brings
   the site and its sitemap across, so there is nothing to verify again.
2. Add an IndexNow key file to `site/`, so that when pages change, Bing, Yandex and the other
   IndexNow engines can be told straight away.

## Why

On 2026-11-04 Bing had no pages from the site. Bing's index also feeds DuckDuckGo, Yahoo,
Ecosia, Copilot and ChatGPT search.

## Done when

Bing Webmaster Tools shows the sitemap as read and `site:seymadrivingschool.com` on Bing lists the
pages.
